# 经济与商店

V0.6 的闭环收尾：种 → 收 → 卖 → 买种子 → 再种。金币是唯一的全局数值，商店只是它的读写界面。

## 金币

`scripts/systems/economy.gd`（`class_name Economy`，挂在 `Main/Systems/Economy`，加入 `economy` 组）：

| 成员 | 说明 |
| --- | --- |
| `coins` | 当前金币，初始 500（`STARTING_COINS`） |
| `can_afford(cost)` | 够不够钱（负数一律视为不够） |
| `spend(cost) -> bool` | 扣钱，钱不够时**不做任何改动**并返回 false |
| `earn(amount)` | 进账，≤0 直接忽略，避免调用方写错把金币扣掉 |
| `changed(coins)` | 任何数值变化后发出，HUD 与商店都订阅它 |
| `coins_gained(amount)` | 只在进账时发出，供 HUD 飘 `+N` |

## HUD

`scenes/ui/hud.tscn` + `scripts/ui/hud.gd`：右上角一枚金币图标 + 数字，复用背包的米色九宫格样式（`InventoryDetails`）。收入时在数字下方飘一个 `+N` 并淡出。只读 `Economy`，不持有状态。

## 商店

`scenes/ui/shop_panel.tscn` + `scripts/ui/shop_panel.gd`：

- **左列买入**：物品表里所有 `buy_price > 0` 的物品（当前是胡萝卜种子 8、番茄种子 12）
- **右列卖出**：背包里所有 `sell_price > 0` 且持有数量 > 0 的物品，行尾显示「单价 × 持有数」
- 交易规则：点击行 = 交易 1 个；按住 `Shift` 再点 = 一次处理整批（卖光持有 / 买到买不起或背包装不下为止）
- 键盘：`↑` `↓` 选择、`空格`（`use_tool`）交易、`Esc` / 点面板外空白关闭
- 底部一行反馈最近一笔：「买入 胡萝卜种子 ×1（-8）」「卖出 木材 ×5（+40）」，失败时显示「金币不足或背包已满」
- 面板打开时锁玩家输入、收起工具栏与左上提示条，并与背包**互斥**（打开一个会自动关闭另一个，避免两个面板抢输入锁）

## 数据来源

商店不写死商品，全部来自物品表：

| 字段 | 作用 |
| --- | --- |
| `buy_price` | >0 才会出现在买入列，数值即买价 |
| `sell_price` | >0 且持有 >0 才出现在卖出列，数值即卖价 |

改价只改 `data/items/*.tres`，加商品只加物品文件，`shop_panel.gd` 不用动。

## 进入方式

商店由**杂货铺老板**（`scenes/npcs/shopkeeper.tscn`）经营：走到老板身边按 `E` 开始对话，在对话选项里选「看看今天的货」才打开商店。老板带有脚底碰撞体，玩家不能穿过去；交互半径 26px，走远就提示不了。

早先放在门口地上的钱袋子（`shop_stand`）已经移除，商店入口完全交给老板 —— 详见 [10-NPC与对话](10-NPC与对话.md)。

`player.gd` 的 `E` 有优先级：**先收成熟作物**（面前优先、其次身边一圈），没有作物时再看附近有没有 `interactable`（老板、睡觉点）；两者都没有才回落成「切换工具」（`E` 与 `tool_next` 共用一个键）。

## 验收

```powershell
godot --headless --path . --script res://tools/check/smoke_check.gd
godot --headless --path . --script res://tools/check/check_shop.gd
godot --headless --path . --script res://tools/check/check_inventory.gd
godot --headless --path . --script res://tools/check/check_crops.gd
```

`check_shop` 覆盖：初始金币、超额支出失败不改数、商店开启锁定输入并收起工具栏、买入列/卖出列内容、买 1 个扣 8 且进背包、卖 1 个木材 +8 且出背包、Shift 整批卖出按单价结算、连续 10 次买 1 卖 1 金币不漂移、金币不足既不扣钱也不给货且给出提示、HUD 数字跟随、关闭后输入与工具栏恢复、背包与商店互斥。

实机流程：出生点就在木屋门口 → 顶部提示「按 E 与农场商店交易」→ `E` 开店 → 点「胡萝卜种子」买几包 → `Esc` 关店 → `1` 开垦 → `3` 播种 → `2` 浇水 → `N` 过一天 → 成熟后 `E` 收获 → 回门口卖胡萝卜，右上角金币即时变化。

## 已知限制

1. 金币不持久化（V0.7 存档一起做）。
2. 没有商品解锁/季节性价格，价格是常量。
3. 卖出只按 1 个或整批，没有数量滑条；买入同理。
4. 音效未接入（路线图允许先用占位）。
5. 商店不能买工具、升级或动物，只有种子。

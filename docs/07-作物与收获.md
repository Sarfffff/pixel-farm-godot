# 作物与收获

V0.5 的播种 / 生长与 V0.6 的收获打通：种子 → 幼苗 → 成熟 → 收进背包，闭环的第一段跑通。金币与商店仍是空白。

## 数据

| 文件 | 作用 |
| --- | --- |
| `scripts/data/crop_data.gd` | `class_name CropData extends Resource`：`id`、`display_name`、`stages`（阶段贴图数组）、`seed_item`、`harvest_item`、`harvest_count` |
| `data/crops/carrot.tres`、`tomato.tres` | 两种作物；`stages` 是“发芽 → 幼苗 → 生长 → 成熟”四张 32×32 贴图 |
| `assets/generated/crops/` | 阶段贴图（按 `crop_growth_v1.png` 图集切出，胡萝卜/番茄/芜菁/小麦各 6 阶段，后两种暂未配 `.tres`） |

加新作物：复制一个 `.tres`，换 `id`、`seed_item`、四张阶段贴图即可，不改脚本。

## 作物节点

`scenes/world/crop.tscn` + `scripts/world/crop.gd`：

- 32×32 `Sprite2D`，`offset = (0, -16)` 让贴图底边落在格子底边，向上占两格。
- 位置由耕地系统设成“格中心 + 8px”，挂在 `Farm/World`（y 排序）下，与角色、树木同一套遮挡顺序。
- 状态：`stage`（0 起）、`watered`（当天是否浇过）。`water()` 未成熟且当天没浇过时推进一阶并弹一下；`is_mature()` 为 `stage == 最后一张贴图`。
- `play_harvest()` 缩放淡出后自行 `queue_free()`。

## 耕地系统接入

`scripts/world/farm_tiller.gd` 新增 `_crops`（格坐标 → 作物）与 `_crop_definitions`（运行期扫描 `res://data/crops`）。

| 操作 | 条件 | 结果 |
| --- | --- | --- |
| 播种（`seeds` 工具） | 该格已开垦、没有作物、背包里有种子 | 扣 1 个种子，生成作物（stage 0），土变干 |
| 浇水（`watering_can`） | **该格有作物**、未成熟、当天没浇过 | 推进一阶，土变湿 |
| 收获（`E`） | 该格作物已成熟 | 收获物进背包，作物播放消失动画，土变干可补种 |
| 锄地（`hoe`） | 该格有作物时一律拒绝 | 防止一锄头铲掉作物 |

**空耕地不能浇水**：当前没有“湿土保持到第二天、省一次浇水”的机制，空地浇了也没有任何收益，只会让玩家误以为“先浇地再种有用”。等 V0.7 有天数系统、湿土能跨天保持时再放开。

## 作用范围与转身

锄地、浇水、收获支持**身边一圈（3×3 去掉脚下）**，播种仍然只作用于面前一格（避免把有限的种子撒错格）。

选目标的顺序（`farm_tiller.resolve_target`）：

1. 面前那一格可用 → 直接用，行为与以前完全一致；
2. 否则按 `面前 → 斜前 → 左右 → 斜后 → 身后` 的顺序，取第一个真正可操作的格子；
3. 一个都没有 → 仍返回面前格，光标变红并给出原因。

动作起手时角色会**转向目标格**（`player._face_cell`），播放对应方向的动画，命中的格子与转身方向一致。这样站在田中间就能连续处理一圈，不必走位对齐；想精确操作某格时，只要先面向它即可。

播种不走范围选择，是因为种子是消耗品，误种不可撤销；成熟作物被周围自动选中则没有这个风险（背包满时还会保留作物）。

- **种子选择**：种子袋只有一个槽位，直接取背包里第一种 `category == seed` 的物品（按格子顺序）。之后接商店可改成“手里拿哪种种子”。
- **背包满**：收获时 `add_item` 返回溢出数量，此时作物**保留在田里**，不会凭空消失。
- **满包/无种子**：提示文案会明确指出原因，不静默失败。
- 作物不会被认成“遮挡开垦的道具”（`_has_prop_overlay` 跳过 `Crop`），所以种满一格的作物不会挡住旁边格的开垦。

## 动作与输入

| 输入 | 行为 |
| --- | --- |
| `空格` / 左键 | 用当前工具（锄地 / 浇水 / 播种 / 砍树） |
| `E` | 收获面前（或身边一圈里）成熟的作物（`interact` → `_try_interact`）；`E` 同时绑着 `tool_next`，只有这一圈没有可收获对象时才回落到切换工具 |
| `N` | **临时调试键**：推进一天，清掉所有作物的浇水标记。V0.7 接入时间系统后由它接管 |

播种沿用锄地的弯腰动画（`player.gd` 的 `ACTION_ANIMATION` 把 `seeds` 映射到 `hoe`），素材里还没有单独的播种帧。命中帧与锄头一致，第 2 帧提交。

## 提示文案

| 目标格状态 | 顶部提示 |
| --- | --- |
| 作物已成熟 | `胡萝卜 已成熟 · 按 E 收获` |
| 作物浇水当天 | `今天已经浇过水 · 明天再浇` |
| 作物未浇水（水壶） | `给胡萝卜浇水 · 空格 / 左键` |
| 作物未浇水（其它工具） | `胡萝卜 正在生长 · 切换水壶浇水` |
| 空耕地（水壶） | `这片地还没有作物 · 先播种再浇水` |
| 空耕地（种子袋） | `播种 胡萝卜种子 · 空格 / 左键` |
| 未开垦（种子袋） | `先用锄头开垦这一格` |
| 没有种子 | `背包里没有种子 · 按 B 打开背包` |

## 验收

```powershell
godot --headless --path . --script res://tools/check/smoke_check.gd
godot --headless --path . --script res://tools/check/check_crops.gd
godot --headless --path . --script res://tools/check/check_farm_interactions.gd
godot --headless --path . --script res://tools/check/check_inventory.gd
```

`check_crops` 覆盖：作物定义加载、种子自动选择、未开垦拒绝播种、播种扣种子、占位格拒绝二次播种、锄头不能铲作物、浇水推进一阶、当天不能二次浇水、连浇三天成熟、成熟后提示收获键、真实 `E` 键收获进背包且不误切工具、无可收获对象时 `E` 回落到切工具、收完可补种、满包时作物保留在田里。

实机流程：`1` 锄头开垦 → `3` 种子袋播种 → `2` 水壶浇水 → `N` 过一天 → 重复浇到成熟 → `E` 收获 → `B` 查看背包。

## 已知限制（下一步）

1. 没有天数系统：`N` 是调试键，作物只能靠手动推进；V0.7 的时间系统会把 `begin_day()` 接到睡觉结算上。
2. 作物只有“未成熟 / 成熟”两态语义，没有枯萎、无多茬重复收获、没有季节限制。
3. 播种时的种子选择是“背包里第一个种子”，还没有种子选择 UI。
4. 收获物只能卖（`sell_price` 已在物品表里），但商店与金币还没做。
5. **工具升级（后续做，不在当前范围）**：锄头/水壶 Lv2 蓄力一次处理面前 1×3，Lv3 处理 3×3。现在的“身边一圈可选目标”只是一格一次、减少走位的过渡方案，效率收益要留给升级：届时需要长按 `use_tool` 蓄力、按等级取作用区、并配合体力或耐久消耗，避免升级后无脑刷地。

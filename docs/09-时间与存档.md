# 时间、睡觉与存档

V0.7 的第一块：有了日期与作息，作物从"浇水立刻长"改成"睡一觉才长"，退出游戏进度不丢。

## 时间系统

`scripts/systems/time_system.gd`（`Main/Systems/Time`，`time` 组）：

| 成员 | 说明 |
| --- | --- |
| `day` / `minutes` | 天数与当天分钟数（06:00 起床，26:00 = 次日 02:00 收工） |
| `MINUTES_PER_REAL_SECOND = 4` | 1 现实秒 = 4 游戏分钟；06:00 玩到 02:00 约 5 分钟真实时间 |
| `time_changed(day, minutes)` | 每变化一次游戏分钟发一次，HUD 与昼夜色调订阅 |
| `day_started(day)` | 睡觉结算时发出，耕地在这里让作物生长 |
| `day_over` | 到 02:00 时发出（当前只用于收工提示） |
| `sleep()` | 日期 +1、时间回到 06:00，然后广播 `day_started` |

时间本身不存档也不碰界面，只发信号。

## 昼夜观感

`scripts/world/day_night_tint.gd` 挂在 `Main/DayNightTint`（`CanvasModulate`）：17:00 起逐渐变暗，21:00 达到最深（混入 55% 夜色蓝），保持到收工。`CanvasModulate` 只影响世界层，UI 的 `CanvasLayer` 不受影响，所以面板与 HUD 始终清晰。

## 作物按天生长

生长从"浇水即推进"改成星露谷式结算：

1. 水壶浇在作物上 → 只打 `watered` 标记，土变湿，提示「浇过水 · 睡一觉就长一阶」
2. 同一天不能重复浇（水壶对该格失效）
3. 睡觉 → `begin_new_day()`：**浇过水的作物 +1 阶**，然后清掉标记、土变干
4. 没浇水的作物睡一觉不长

`Crop` 的接口随之拆开：`water()` 只标记，`grow_if_watered()` 在结算时推进，`apply_stage()` 供读档恢复阶段。

## 睡觉与日报

- `scenes/world/sleep_spot.tscn`：木屋门口（`Farm/World/SleepSpot`，半径 26px），靠近提示「按 E 回屋睡觉 · 今天第 N 天 HH:MM」
- `scenes/ui/day_summary.tscn`：`第 N 天结束` + 今日收获件数 + 今日收入 + 金币余额，底部「睡觉 · 进入下一天」按钮；`E` / `Enter` 确认，`Esc` 或点空白取消
- 商店摊位挪到门口右侧（`ShopStand` at 488,152），与睡觉点分开，按 E 时取最近的一个

今日统计：`Economy.today_income`（`earn` 累加）与 `Inventory.today_collected`（`add_item` 累加），都在 `day_started` 时清零。

## 存档

`scripts/systems/save_system.gd`（`Main/Systems/Save`，`save` 组）：

- **三个槽位**：`user://save_1.json` ~ `save_3.json`，顶层带 `version`（当前 1）与 `saved_at`（unix 秒）
- 内容：`time{day,minutes}`、`coins`、`inventory.slots[]`、`farm{tilled[],watered[],crops[]}`、`player{x,y}`
- 当前槽位：主菜单选好后 `use_slot(slot)` 写进 `Engine` meta（`pending_save_slot`），进农场时 `SaveSystem` 读它，之后的保存都写这个槽位
- 时机：睡觉后自动存、关闭窗口时存（`NOTIFICATION_WM_CLOSE_REQUEST`）、启动时自动读当前槽位
- 容错：文件损坏 → 复制成 `save_N.json.broken` 并删除原文件，该槽位按空档处理；缺字段 → 各系统退回默认值；未知物品 id 与越界格坐标跳过
- 测试用 `SaveSystem.autoload_enabled = false` 关掉自动读档（实例化后立刻设置，早于 deferred 读档）

### 主菜单选档

「继续游戏」不会直接进游戏，而是先弹槽位列表，每行两行文本：

```
存档 1 · 我的农场                        [改名] [删除]
第 1 天 · 500 金币 · 11-03 16:40
```

第一行是槽位号 + **农场名**，第二行是进度与保存时间；空槽位在继续模式下置灰。「新游戏」走同一个列表，标题变成「存到哪个槽位？」，选中已有存档的槽位会提示「（将覆盖）」。

**新游戏起名**：选完槽位先弹「给农场起个名字」，输入框预填「我的农场」（第 2、3 槽位是「我的农场 2/3」），回车或点「确定」才真正开局；名字写进存档的 `name` 字段，长度上限 16 字（`_name_input.max_length`）。新档进游戏时会先落一次盘，所以标题界面立刻能看到名字与天数。

**改名**：已有存档的行带「改名」按钮，复用同一个命名面板，只重写 `name` 字段、不动进度（`SaveSystem.rename_save`）。

**删除存档**：有档的槽位行右侧带「删除」按钮，点一次变成「确认?」，再点才真的删（防止误触），删完标题提示「已删除存档 N」并重建列表；空槽位不显示删除入口。删除只影响该槽位，其他槽位不受影响；全部删完后返回主菜单，「继续游戏」会自动置灰。

槽位信息由 `slot_summary(slot)` 现场读文件解析，不额外维护索引文件 —— 存档坏了也不会让标题界面崩。存档名存在 JSON 的 `name` 字段里，旧档没有这个字段时显示默认的「我的农场」。暂不做「存档复制」：三个槽位各自独立，复制对单人农场玩法没有实际价值。

各系统提供序列化接口：`Inventory.to_dict/from_dict`、`FarmTiller.to_dict/from_dict`，时间与金币由 `SaveSystem` 直接读写字段。

## 标题与暂停

- **标题界面** `scenes/ui/main_menu.tscn`（项目主场景）：`小农场` + 「继续游戏 / 新游戏 / 退出」。有存档时「继续」可点并默认聚焦，无存档时置灰、焦点落到「新游戏」。新游戏会先删除旧档再进农场，避免刚开局就被旧存档覆盖。
- **暂停菜单** `scenes/ui/pause_menu.tscn`（`Main/UI/PauseMenu`）：`Esc` 打开，`get_tree().paused = true` 停住时间与世界，面板自身 `PROCESS_MODE_ALWAYS` 保持可交互。三个选项是「继续游戏 / 保存游戏 / 保存并返回标题」；`Esc` 或「继续」恢复，返回标题前会先存档。
- **Esc 优先级**：背包 / 商店 / 日报任一打开时 `can_pause()` 返回 false，Esc 交给面板关闭；都关闭时才弹暂停。这样不会出现「关面板同时把游戏也暂停了」。

## 已知限制

1. 没有主菜单与暂停菜单（下一个增量），ESC 目前只用于关面板。
2. 睡觉不消耗金币、没有"体力/困倦"设定。
3. 02:00 到点只发 `day_over`，还没有"累倒"动画。
4. 存档只有单槽位，没有手动存档按钮。
5. 作物不会枯萎、没有季节。

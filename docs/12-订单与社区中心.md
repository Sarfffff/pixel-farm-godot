# 订单与社区中心

前面几版把「种 → 收 → 卖」做通了，但第 3 天之后就没有新东西可追：钱多了也只能买同样的两种种子。这一版补两层目标感：

- **日订单**（短期）：今天交一批货，拿比直接卖更高的价
- **社区中心**（长期）：分三阶段上缴物资，每修好一段就解锁新种子

## 日订单

`scripts/systems/orders.gd`，挂在 `Main/Systems/Orders`（组 `orders`）。

**生成规则**：监听 `TimeSystem.day_started`，每次睡觉换一张。

```
订单池 = 物品表里 category == "crop" 且 unlock_stage <= 社区阶段 且 sell_price > 0
物品    = 池子里随机一种
数量    = 3–6
报酬    = 卖价 × 数量 × 1.7（取整）
```

所以胡萝卜（卖 25）会变成「5 个胡萝卜 · 212 金币」，比直接卖 125 划算，玩家有动力攒货交单。

**交付**：`deliver()` 检查背包、扣货、`Economy.earn(reward)`、标记 `done`，然后立刻存档。同一天不能再交第二遍，睡醒才有新单。

**入口**：木屋旁的麻袋（`scenes/world/props/order_bin.tscn`，`(440,168)`），靠近按 `E` 打开 `UI/OrderPanel`。

面板显示图标、名称、`已备 / 需求`、报酬；材料不够时按钮变灰显示「货物不够」，够了按 `E` 或点按钮交付。

## 社区中心

`scripts/systems/community_center.gd`，挂在 `Main/Systems/CommunityCenter`（组 `community`）。

阶段表写在脚本里（`STAGES`），不依赖素材：

| 阶段 | 名称 | 需求 | 奖励 | 解锁 |
| --- | --- | --- | --- | --- |
| 1 | 修补围栏 | 木材 15 + 纤维 10 | 300 金币 | 萝卜种子上架 |
| 2 | 翻新集市 | 胡萝卜 10 + 鸡蛋 5 | 500 金币 | 小麦种子上架 |
| 3 | 装点农场 | 小麦 8 + 石头 10 | 800 金币 | 农场招牌挂上了 |

- `can_donate()`：当前阶段每一项都够才能交
- `donate()`：扣材料 → 阶段 +1 → 发奖金 → 发信号 → 自动存档
- `unlocked_stage()`：给商店用的解锁阶段号
- `progress()`：把「需求 / 持有」整理成面板能直接渲染的行

**入口**：`scenes/world/props/community_building.tscn`，放在地图左下 `(120,416)` 的空地上（脚本扫过全图，这块不压水也不压道具）。建筑用 `buildings/facilities/community_center.png`（96×80），碰撞只覆盖墙体下半部分 92×34。

面板 `UI/CommunityPanel` 显示：第几阶段 · 名称、描述、每项需求的 `持有 / 需求`（够了绿色、不够红色）、奖励与解锁内容、上缴按钮。

## 作物解锁

`ItemData` 新增 `unlock_stage`：

```gdscript
@export var unlock_stage: int = 0   # 0 = 一开始就能买
```

商店买入列表在 `_rebuild()` 里过滤 `item.unlock_stage <= community.unlocked_stage()`，被挡下的不显示货行，而是在列表末尾加一行灰字「还有 N 种货没解锁 / 去社区中心看看」，给玩家一条明确的下一步。

## 新作物：萝卜与小麦

素材里本来就有这两种作物的 6 张图（sprout / young / growing / mature / harvest / seeds），之前一直没用。

| 作物 | 种子买价 | 收获卖价 | 解锁阶段 |
| --- | --- | --- | --- |
| 胡萝卜 | 8 | 25 | 0 |
| 番茄 | 12 | 40 | 0 |
| 白萝卜 | 16 | 50 | 1 |
| 小麦 | 26 | 80 | 2 |

播种怎么选？之前 `_seed_id()` 取背包里**第一个**种子，解锁第二种作物后就卡住了。现在改成：

- `FarmTiller` 记一个 `_selected_seed`，拿种子袋时按 `Q / E` 在「背包里还有库存的种子」之间轮换，并弹提示「种子：白萝卜」
- 手选的那种用完了，`_seed_id()` 自动退回背包里的第一种
- 其他工具时 `Q / E` 照旧切换工具

## 存档

`SaveSystem` 加了两个字段：

```json
"community": { "stage": 1 },
"orders": { "item": "carrot", "count": 4, "reward": 170, "done": false, "day": 3 }
```

读档顺序有讲究：**先恢复社区阶段，再恢复订单** —— 订单池按解锁阶段筛选，顺序反了会把已解锁作物的订单读成空。旧档没有这两个字段时走默认值（阶段 0、订单为空则重新生成一张）。

## 验收

```powershell
godot --headless --path . --script res://tools/check/check_goals.gd
```

`check_goals` 覆盖：

- 订单箱、社区中心建筑、两个面板都在主场景里
- 开局阶段 0、自动有一张订单（数量 ≥3、报酬 >0）
- 阶段 0 时商店只卖胡萝卜/番茄种子，萝卜/小麦种子被挡
- 上缴第一阶段：材料被扣、300 金币到账、萝卜种子上架、小麦仍然锁着
- 交付订单：货被收走、奖金到账、当天不能再交第二次
- 睡一觉后有新订单
- `community` / `orders` 存档往返一致
- 三个阶段依次上缴到「全部修好」，修完后不能再交

## 已知限制

1. 订单只有「交作物拿钱」一种，没有 NPC 指名的、限时的、多选的订单。
2. 社区中心是纯上缴，修完没有视觉变化（建筑贴图不变），只解锁商品。
3. 没有季节 / 天气，订单不会因为下雨涨价。
4. 一天只有一张订单，做完就空着了。

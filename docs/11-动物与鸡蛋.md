# 动物与鸡蛋

第一条产出线是种地，这一版补上第二条：鸡在窝边踱步，每天下蛋，捡起来卖钱。

## 素材

| 素材 | 尺寸 | 用法 |
| --- | --- | --- |
| `assets/game/characters/free_chicken_sprites.png` | 64×32 | 4 列 2 行，16×16 帧 |
| `assets/game/characters/egg_and_nest.png` | 64×16 | 4 帧：蛋 / 小蛋 / 巢+蛋 / 空巢 |
| `assets/game/objects/egg_item.png` | 16×16 | 背包与商店图标 |

鸡的帧序（像素比对确认，不是常规的四向图集）：

| 帧 | 内容 |
| --- | --- |
| 0 / 1 | 朝右 / 朝左 待机 |
| 4 / 6 | 朝右 走路 A / B |
| 5 / 7 | 朝左 走路 A / B |

素材没有上下两向，所以鸡往上下走时保持当前朝向 —— 鸡本身很小，读不出来也不违和。

## 鸡

`scenes/world/chicken.tscn` + `scripts/world/chicken.gd`：

```
Chicken (CharacterBody2D, motion_mode = FLOATING)
├─ Sprite (Sprite2D, hframes=4, vframes=2, offset(0,-7))
└─ Body (CollisionShape2D, 8×6, position(0,-3))
```

- 用 `CharacterBody2D + move_and_slide`：鸡自己绕开树、窝、房子，不需要寻路
- 游走范围以**出生点**为圆心，`home_radius = 40`，纵向按 0.6 压缩
- 到点后停 0.8–2.4 秒（`randf_range`），再挑下一个点
- 撞到东西（`get_slide_collision_count() > 0`）立刻换目标，不会贴着障碍物抖
- 走路帧 0.24 秒切一次，速度 16 px/s，看起来像在踱步

鸡是 `CharacterBody2D`，与玩家不会互相阻挡 —— 玩家不会被鸡堵在门口。

## 鸡窝

`scenes/world/props/chicken_coop.tscn` + `scripts/world/chicken_coop.gd`：

- 视觉用 `egg_and_nest` 的「巢+蛋」帧，放大 2×（32×32），配一块 26×10 的静态碰撞
- 没有专门的鸡舍建筑贴图（`free_chicken_house.png` 已被农舍占用），先用鸡窝代替；等有正式鸡舍素材再换
- 放在 `Farm/World` 的 `(520,264)`，避开可开垦区（`Rect2i(16,5,14,10)`）和玩家出门的动线

## 下蛋规则

监听 `TimeSystem.day_started`（睡觉结算后触发）：

```
每天产蛋数 = min(鸡的数量, 3 - 地上的蛋)
```

- 地上最多留 3 颗，捡不完也不会铺满地图
- 落点从 5 个候选位（窝左右各两个 + 正前方）里随机挑，离已有蛋不足 10px 就换一个
- 蛋生成到**父节点 World**，而不是鸡窝下面 —— 这样蛋、鸡、房子共用同一套 Y 排序

## 捡蛋

`scenes/world/egg.tscn` + `scripts/world/egg.gd`：

- 加入 `interactable` 与 `egg` 组，交互半径 20px，提示「按 E 捡起鸡蛋」
- 捡起走 `Inventory.add_item(&"egg", 1)`：返回 0 才 `queue_free()`，返回 >0（背包满）就留在地上并弹提示
- 捡走的蛋会通知鸡窝 `forget_egg()`，存档里就不会留着一颗不存在的蛋

## 物品与售卖

`data/items/egg.tres`：`id = egg`、卖价 50、买价 0。

商店的买卖列表按物品表过滤（`buy_price > 0` 才出现在「买入」），所以鸡蛋只出现在卖出列，不需要改商店代码。

## 存档

`SaveSystem` 多了一个 `coop` 字段：

```json
"coop": { "eggs": [[520.0, 274.0], [534.0, 270.0]] }
```

- 只存地上的蛋；鸡自己在附近随机游走，读档后重新在出生点附近散步，不记精确位置
- 读档时 `from_dict()` 先清空现有蛋，再按坐标重建
- 旧档没有 `coop` 字段时走默认值（地上没有蛋），不会报错

## 按键说明面板

顺手把「现在能按什么」做成可查的：`scenes/ui/help_panel.tscn` + `scripts/ui/help_panel.gd`。

- `F1` 打开/关闭，暂停菜单里也有「按键说明」入口（第 4 个按钮）
- 打开时暂停游戏树并锁玩家输入，收起工具栏；与背包/商店/日报/对话/暂停互斥
- 内容写在脚本的 `ROWS` 数组里，改键位只改这张表

当前键位：

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 交互 · 收获 · 捡蛋 | E |
| 和杂货铺老板说话 | E（走近他） |
| 使用当前工具 | 空格 / 鼠标左键 |
| 切换工具 | 1 2 3 · Q / E |
| 背包 | B |
| 暂停菜单 | Esc |
| 按键说明 | F1 |

> `E` 同时是「交互」和「下一个工具」，优先级是：先收成熟作物 → 再看附近 `interactable` → 都没有才切工具。

## 验收

```powershell
godot --headless --path . --script res://tools/check/check_animals.gd
godot --headless --path . --script res://tools/check/check_pause.gd
godot --headless --path . --script res://tools/check/smoke_check.gd
```

`check_animals` 覆盖：场景里 2 只鸡 + 鸡窝、鸡会走动、图集切分 4×2、睡觉后每只鸡一颗蛋、蛋在存档里往返、捡蛋进背包且鸡窝同步、鸡蛋有卖价、满包时蛋留在地上。

`check_pause` 覆盖：帮助面板存在、F1 打开会暂停、关闭恢复、暂停菜单里能打开帮助。

## 已知限制

1. 没有正式鸡舍建筑，用「巢」代替。
2. 鸡不会饿、不用喂食，也没有好感度。
3. 只有鸡一种动物；牛素材（`free_cow_sprites.png`）留着以后用。
4. 蛋的价格写死在 `.tres`，没有随季节/供需波动。

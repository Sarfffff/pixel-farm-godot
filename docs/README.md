## 截图与预览图

`docs/screenshots/` 只当输出目录用：`tools/art/preview_*.gd`、`tools/check/check_farm_activities.gd` 等脚本
会把预览图/回归截图写到这里。该目录带 `.gdignore`（Godot 不导入），内容也不提交仓库。

## 职责边界

- `CODEBUDDY.md`：仓库结构、常用命令、协作方式 —— 给 AI 和工作流看的，不写设计取舍。
- `README.md`（根目录）：玩法介绍与截图，面向玩家/访客。
- `tools/README.md`：离线工具脚本索引（生成、切片、回归各是哪个脚本）。
- `assets/generated/README.md`：生成产物的目录规范与素材来源。
- `docs/`（本目录）：设计决策、路线、素材清单。

## 职责边界

- `CODEBUDDY.md`：仓库结构、常用命令、协作方式 —— 给 AI 和工作流看的，不写设计取舍。
- `README.md`（根目录）：玩法介绍与截图，面向玩家/访客。
- `tools/README.md`：离线工具脚本索引（生成、切片、回归各是哪个脚本）。
- `assets/README.md`：当前成品查找入口、分类与素材来源索引。
- `art/README.md`：原图、提示词、预览和外部参考资料索引。
- `scripts/README.md`：按业务职责分类的代码入口。
- `docs/`（本目录）：设计决策、路线、素材清单。

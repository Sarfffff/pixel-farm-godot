# Pixel Farm · 像素农场

Godot 4像素农场游戏：种植、采集、出售、升级和再生产，并可保存继续。当前技术版本0.9.0，仍在开发，功能接入与发布验收分别管理。

## 当前可体验内容

- 原40×30农场：锄地、播种、浇水、六种作物、季节播种限制、部分复收。
- 经营循环：背包、商店、金币、铜水壶三格浇水、订单、社区交料和引导手记。
- 时间与恢复：昼夜、天气、体力、床边小睡/过夜、累倒返回及三槽存档。
- 农场活动：木箱、野浆果和采集、番茄腌制、基础钓鱼、鸡与鸡蛋、村民日程/对话/好感。
- 第一章：四位NPC的六个顺序委托、任务日志与单目标追踪、信箱、可跳过章节事件；完成后集市点灯，并开放农舍木桌的留种制作。
- 六个野外区域：荒地、村庄、林地、湿地、采石区、海滩；路标切换、28类资源采集、地面掉落和按天再生。
- 界面与表现：背包分类和快捷位、暂停/设置、视野缩放、室内、音乐音效、四季天气表现。

原农场承担种植、商店、加工与睡眠；新地图主要用于采集探索。完整主线、冶炼、多级工具、动态动物经营和全年平衡仍按[开发总纲](docs/04-后续开发总纲.md)推进。自动检查通过不等于新玩家试玩或Windows发行已验收。

## 快速开始

使用Godot 4.7.x打开 `project.godot`，F5运行标题场景；或在项目根目录执行：

```powershell
pwsh -NoProfile -File tools/run_game.ps1
```

主场景为 `scenes/ui/main_menu.tscn`，默认窗口1600×900、基准视口640×360。引擎查找、命令参数和导出入口见[工具索引](tools/README.md)。

## 操作

| 按键 | 用途 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 空格 / 鼠标左键 | 使用当前工具 |
| F | 对话、路标切区、收获、采集、拾取、床边与设施交互 |
| Q / E、1–8 | 切换工具/种子或选择快捷位 |
| B | 背包；选中物品可按数字绑定快捷位或拖拽 |
| J | 展开/收起农场手记 |
| K | 章节任务日志；查看材料、地点、奖励和追踪目标 |
| Esc / F1 | 暂停菜单 / 按键说明 |
| 滚轮、+/-、Home、F11 | 镜头缩放、复位、全屏 |

按F1查看游戏内完整说明。从农场东侧路标按F出发；木材用斧、岩矿用镐、软资源按F，采完再靠近按F拾取。细节以[系统设计](docs/02-系统设计.md)和[地图规则](docs/05-地图类型与地面资源.md)为准。

## 开发与验证

框架采用业务模块分层、应用服务、MVP界面和Godot节点组件，依赖由GameSession装配。修改前阅读[AGENTS](AGENTS.md)与[架构规范](docs/06-架构与开发规范.md)。完整回归命令：

```powershell
pwsh -NoProfile -File tools/run_checks.ps1
```

入口建立固定源码/素材快照与独立用户目录，检查编译、玩法、脚本/引擎错误、退出泄漏及实际PCK导出运行。不得用玩家槽位测试；指定套件、窗口复测与资源重建命令统一见tools索引。历史证据见[验证索引](docs/validation/README.md)。

# 分类贴图

这里是早期原创成品和基础图块，按用途分目录。后续整套素材在 [packs](../packs/README.md)，生成大图在 [art/sources](../../art/README.md)。

| 目录/文件 | 内容 |
| --- | --- |
| `base/characters`、`base/objects`、`base/tilesets` | 工程原有基础角色、道具及16px图块，保留已有引用与来源记录 |
| `characters/` | 玩家工具动作、持物图集、NPC 行走及方向图；清单与图集放在一起 |
| `crops/` | 基础作物生长阶段和收获物 |
| `items/` | 种子、材料、果实与工具图标 |
| `buildings/` | 住宅和设施外观储备、图标、catalog |
| `trees/` | 树木、果树、生长与季节图集 |
| `terrain/` | 耕地与地形图集 |
| `field/` | 农田摆设 |
| `manifest.json` | 基础动作、作物与物品图集排列 |
| `prompts.json` | 对应生成记录 |

预览已移到 `art/previews/<类别>/`。原来的生成素材说明作为历史记录保存在 [archive/docs](../../archive/README.md)，当前查找入口以 [assets/README.md](../README.md) 为准。
